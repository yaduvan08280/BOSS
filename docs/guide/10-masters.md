# 10. Masters

"Enter it once. Every module reads the same customer, item and person."

## Master Library
Masters → **Master Library**: ready masters by industry (Vendors, Products, Raw materials, Machines, Spare parts,
Vehicles, Sites, Transporters, Services, Brands, Stores, Documents). **Use this** → it is yours, fields and all.
You can change its fields afterwards in My Masters.

## Build my own
Masters → **Build my own**: describe it in plain words ("our trucks: number, kind, driver, insurance and fitness
dates") → the AI proposes fields → edit → save. Set a **unique key** (e.g. Vendor code) and the field rows show as.

## Rows
My Masters → **Open** a master:
- **Add a row**, change it (pencil), or delete it (it leaves the list; records that used it keep their text).
- A key can be used only once in a master.
- **Import:** an Excel file (.xlsx), a CSV, rows pasted from a sheet, or a **Google Sheet link** (shared as "Anyone
  with the link can view"). The first row names the fields. Dates as DD/MM/YYYY. All rows go in, or none — every
  problem is listed with its line number so you can fix the file and try again.

## Using masters in forms
In the FMS Builder, a field of type **From a master** picks Customers, Items, Vendors, People or any of your own
masters. People filling the form search the list as they type.
