# 2. Delegation (one-time tasks)

Every task has a **doer**, a **planned date** and (usually) a **verifier**. Menu: Business Engine → Delegation sheet.

## Give a task
1. **Add task** → pick the doer, the planned date and time, a verifier if someone should check it.
2. Describe it (or press **Dictate** and speak). Attach photos or files: drag them in, use the camera, or paste a
   screenshot with Ctrl+V.
3. Tick "Require a photo or file when this is marked done" if a remark alone is not enough.
4. **Submit task** — the doer gets it on Telegram. Many tasks at once: **Import many** (Excel/CSV).

## When you are the doer
| You want to | Press |
|---|---|
| Take the task | **Accept** (or Decline with a reason) |
| Ask for more time | Calendar icon → new date + why. Each change counts as a revision. |
| Say where it stands | **Follow up** or write a **note** |
| Hand the next part to someone | **Pass on** → what you did, who does the next part, by when |
| Finish it | **Mark done** → what was done + proof → it goes to the verifier |

## When you are the verifier
Tab **Verification**: open the task, check the proof → **Verify** (done) or **Reject** with a comment (it reopens).
Verify within an hour; late verifications show in the scorecard. Nobody verifies their own work.

## Colours and scores
- Status chips: Awaiting acceptance · Accepted · Verifier: name · Covered by (Buddy) · overdue 2d.
- **R/Y/G report:** Green = on time and never revised · Yellow = a day late or revised once · Red = 2+ days late or
  revised twice+.
- **Scorecard** (week by week): work done %, on time %, verifications done and within 1 hour, against the benchmark.

## Good habits
- Put the real date. Moving dates is allowed, but it shows.
- Write the result in "what was done", not "done".
- A chain that repeats every time (order → dispatch → invoice) belongs in a **Process (FMS)**, not in pass-ons.
