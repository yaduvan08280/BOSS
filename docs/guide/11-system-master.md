# 11. System Master (setup)

Only the owner and admins see **System Master** (the switch in the top bar). The cards on top show setup progress,
processes, people load and a **health check** ("See what is missing").

| Tab | What you set |
|---|---|
| Company Setup | Profile (GSTIN Verify), shifts & timings, branches, designations |
| Departments | Type a name and press Enter; HOD; sub-departments (drag one card onto another) |
| Users | One by one or **Paste a list**; login on/off; reset password (one-time password); bulk actions |
| Roles | Permission matrix per module (view / create / edit / approve / admin) |
| Org Chart | Drag a person to another department: **Also add** or **Move**; drop on the top slot = make HOD |
| Integration | WhatsApp, message templates, Telegram links, channels, notification rules, reminders, AI, Google Drive |
| Inventory | IMS rule sets and who does what |
| Sales CRM | Your own fields per record type |
| API Keys | Server address, keys for outside tools, webhooks (guide 12) |
| HR Rules | The 7-step wizard (late, punches, leave, Buddy, autopilot) |
| Business details | Your business in your words — every AI answer uses it |
| Appearance | One colour → the whole theme; corners, sidebar, logo, app name, dark mode, language |
| Errors | What went wrong in the server, the worker or someone's browser — grouped, counted, "Mark fixed" |

## Flow designer (Business Engine card)
For Delegation, Checklists, Help Slips, Help Tickets and the EA system: who does it, time limits, which steps are on.
"Recent changes by admin" shows who changed what. **Reset to default** brings back the original settings.

## Notification rules
When (event) → for whom → which channels (Telegram, WhatsApp, email, in-app) → wait → if no reply, escalate to …
Quiet hours (21:00–07:00) hold everything except escalations.
